# mini_vo：手写最小双目视觉里程计

## 目标与协作方式

参考高翔《视觉 SLAM 十四讲》及本地 `../slambook2`，使用 C++、OpenCV 和 Eigen，独立实现一个能在 KITTI 双目序列上运行的最小视觉里程计（VO）。第一阶段聚焦 VO，完整 SLAM 所需的回环和全局优化留待后续学习。

核心流程：

```text
读取左右目图像
    ↓
提取 ORB 特征并进行双目匹配
    ↓
由双目几何恢复三维点
    ↓
匹配上一帧与当前帧的左目特征
    ↓
构建 3D–2D 对应关系
    ↓
PnP + RANSAC 估计相邻帧运动
    ↓
累计相机位姿
    ↓
保存轨迹，并为下一帧建立双目三维点
```

学习者负责手写代码，助手负责拆解任务、解释数学与接口、审查实现和协助定位问题。每次只推进一个可验证的小任务。

ORB、描述子匹配和 PnP 调用 OpenCV；数据关联、双目几何、位姿累计和程序组织自己实现。

模块职责：

| 模块 | 职责 |
| --- | --- |
| `Camera` | 保存内参和双目基线，提供投影、反投影功能 |
| `Frame` | 保存图像、时间戳、ORB 特征与描述子、位姿以及按左目关键点索引关联的有效三维点 |
| `Dataset` | 读取 KITTI 标定、时间戳和左右目图像 |
| `Frontend` | 完成特征匹配、双目建点、相邻帧运动估计和位姿累计 |
| `run_kitti` | 读取配置，组织逐帧处理并保存轨迹 |

已有的空 `feature.h`、`mappoint.h` 和 `map.h` 暂时保留，第一版不需要实现独立的特征、地图点和地图管理体系。也暂不单独增加 `VisualOdometry` 封装。

## 分阶段实现

### 1. 工程与数据读取

- 完成 CMake，建立 `run_kitti` 程序，链接 OpenCV 和 Eigen。
- 在配置中指定 KITTI 序列目录。
- 实现 `Dataset`，读取序列中的 `calib.txt`、`times.txt` 和 `image_0/image_1`。
- 使用原始分辨率灰度图；相机标定从对应序列读取，不直接照搬书中示例的参数。
- 按顺序读取成对图像，打印帧号、时间戳和图像尺寸，区分正常序列结束与文件缺失。

验收：能够正确读取第一对图像，再扩展到按顺序遍历序列。

### 2. 相机模型与帧数据

- 实现 `Camera` 的内参、基线及投影、反投影接口。
- 实现 `Frame`，保存后续步骤需要的数据。
- 用左目关键点索引关联三维点，并显式区分有深度和无有效深度的特征。
- 先使用普通数据结构，避免过早引入复杂的对象关系。

验收：已知三维点投影后，结合已知深度能恢复原坐标。

### 3. 单帧双目建点

- 左右目分别提取 ORB 特征。
- 使用 Hamming 距离进行描述子匹配，结合比值筛选并保证匹配唯一性。
- 根据校正后的双目几何，过滤纵向偏差大和视差无效的匹配。
- 根据标定和视差计算深度，处理左右主点差异，恢复左相机坐标系下的三维点。
- 保留三维点与左目关键点之间的索引关系。

验收：可视化双目匹配，统计有效深度点数量，检查左右目重投影误差。

### 4. 相邻帧运动估计

- 匹配上一帧左目与当前帧左目的 ORB 描述子。
- 根据上一帧关键点索引取得有效三维点，建立“上一帧三维点—当前帧二维点”对应关系。
- 使用 `solvePnPRansac` 估计相邻帧运动。
- 记录对应点数、内点数和重投影误差。
- 对应不足或估计失败时停止运行，报告失败帧号并保留已输出的轨迹。

验收：使用已知运动的合成数据检查估计结果，再检查真实相邻图像上的对应关系与内点情况。

### 5. 连续运行与轨迹输出

- 将第一帧左相机坐标系设为世界坐标系，初始位姿为单位变换。
- 统一约定 `T_ab` 将 b 坐标系中的点转换到 a 坐标系。
- PnP 得到 `T_cur_prev`，保存的相机位姿按下式累计：

```text
T_w_cur = T_w_prev × inverse(T_cur_prev)
```

- 每帧通过双目重新建立该帧左相机坐标系下的三维点，供下一帧使用。
- 输出 KITTI 格式轨迹：每帧一行，按行展开 `T_w_c` 的前 3 行，共 12 个数，包含第一帧的初始位姿。

验收：连续处理一段序列，轨迹行数与成功处理的帧数一致，位姿数值有限，输出逐帧跟踪统计。

## 验证与完成标准

- 用合成数据验证投影与反投影、双目深度、已知运动的 PnP，以及位姿累计方向。
- 用实际图像检查匹配索引是否正确传递，避免二维点与三维点错配。
- 默认以 KITTI 00 序列前 100 帧作为首次集成验收，数据路径通过配置提供。
- 第一版完成标准：连续处理上述 100 帧，轨迹输出正确，数值有限，并能查看每帧的匹配、有效三维点和 PnP 内点统计。
- 有真值时比较轨迹，保留双目尺度，不通过尺度拟合掩盖尺度错误。
- 学习验收：能够解释每个模块的输入输出、三维点所属坐标系，以及为什么累计位姿时需要对 PnP 结果取逆。
